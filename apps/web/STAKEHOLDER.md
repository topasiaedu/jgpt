# Jeff IP test (stakeholder guide)

## What this is

A single-page chat for trying Jeff-aligned answers about personal IP, brand, trust, content, and positioning. Answers are grounded in the repo teaching store (`jeff-graph` + `jeff-wiki`), not open-web invention and not Dev wiki.

This is a **draft** teaching graph from early transcript ingest. It is not the full Jeff corpus. Do not treat every answer as settled IP doctrine.

## How to try it

1. Open the shared Vercel URL (or run locally: see README).
2. Ask about IP / positioning, or tap an example question.
3. Read the reply. Each Jeff bubble has a top-right sources chip (`3 sources` or `No graph source`). Tap it for id / title / type. The right **Sources used** panel stays in sync with the latest reply, or with the bubble you selected.
4. Try one in-coverage question and one off-topic or niche-script question. Off-topic should still answer with a light general frame, a Jeff pivot, and a steer question (not a blank refuse). Niche scripts should be labeled as example structure for *your* practice, not as Jeff workshop case studies. Empty sources mean general steer, not a fake citation.

## How to report a bad answer

Paste back to builders:

1. The exact question you asked
2. The full assistant reply
3. The **Sources used** / bubble chip node ids (or note if it shows **No graph source** / general steer)
4. What felt wrong (wrong Jeff framing, invented framework name, invented Jeff patient story / niche script, too soft on a reject, dense unreadable blob, etc.)

Do not ask builders to “loosen” the model into inventing Jeff rules. Bad answers usually mean the graph/wiki need ingest fixes.

## Caveat

Graph status is still partly `draft` / `suggested`. Nodes with doctrine `unknown` or status `suggested` are not confirmed named Jeff frameworks.
