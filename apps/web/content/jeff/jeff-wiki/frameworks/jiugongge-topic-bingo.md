# Framework: 九宫格 (Topic Bingo)

**Status:** draft  
**Doctrine:** endorse (named on Day 2 offline workshop slides; steps from OCR only)  
**Day:** D2  
**Also labeled:** Topic Bingo / 九宫格选题

Named topic-generation grid taught on Day 2. Center cell is 人设; eight surrounding cells hold topic keywords. Students then draw **四条穿心线** (see [穿心线](crossing-lines.md)) to get content directions, then expand into the **30天内容系统**.

## Structure (from slides)

1. Center: 人设
2. Eight cells: 兴趣 / 专业 / 观点 / 故事 / 客户 / 行业 / 趋势 / 痛点
3. Draw 4 穿心线 → four content directions
4. Each line → at least 3 topics (worksheet target: 一张九宫格 + 12个题目雏形)

Slide framing: bosses should not rely on daily inspiration; sit once and fill the grid.
