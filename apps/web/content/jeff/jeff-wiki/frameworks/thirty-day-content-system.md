# Framework: 30-day content system / 30天内容系统

**Status:** draft  
**Doctrine:** endorse (named on offline workshop slides; steps from OCR)  
**Day:** D2

Expand the filled [九宫格](jiugongge-topic-bingo.md) into a 30-day executable topic bank.

Slide line: “把九宫格，展开成可执行的30天内容系统。”  
Expansion math on slide: 4 条穿心线 × 每线延展 7–8 题 ≈ 30-day bank. Weekly themes on the expand sheet include 信任引擎 / 内容资产 / 评论护盾 / 创办人故事.

## Steps

1. Start from completed 九宫格 (see dedicated framework page)
2. Use 4 穿心线 as content directions
3. Extend each line to ~7–8 topics → ~30-day bank
4. Place topics into the 30-day expand calendar (weeks as labeled on D2 sheet)
