# Guardrails

Hard constraints for any teaching-facing compose step.

1. **Allowlist only** — doctrine from compiled Jeff sources; no open-web completion.
2. **Bound claims** — Jeff-attributable statements need graph nodes + citations; else strip.
3. **Access wall** — never emit Dev / Cursor wiki content to students or teaching-eval answers.
4. **Reject nodes win over politeness** — if Jeff warns against X, do not bless X as “also fine.”
5. **No educator relativizing** — keep Jeff’s authority; steer into what he teaches.
6. **Out-of-coverage** — Generally → Jeff → steer; never KB-meta refuse.
7. **Legal line** — teaching frameworks and patterns only; no case-specific filings advice.
8. **Status honesty** — Suggested / draft ≠ approved doctrine.
9. **File-back** — drafts go to `jeff-wiki/draft/`; humans promote.
10. **Sufficiency** — do not ship student UI until eval bars in `dev-wiki/architecture.md` pass (or Jeff accepts a narrower limited release under the same rules).
